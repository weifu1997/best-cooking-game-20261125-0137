Ember Kitchen — a wok-fire cooking rush. Take orders from the board, chop veg and chicken, wok the noodles, plate the dish, and ring the bell at the serving window before patience runs out. Serve fast for tips; miss an order and you lose a heart. Three hearts, one 2:30 shift.

## Run it

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080/game/index.html in desktop Chrome. WASD or arrow keys to walk, E (or click) to use a station, P to pause, M to mute. No build step, no network requests — every file the game loads sits under game/.
